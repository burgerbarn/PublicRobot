# lightBot scripts

Everything the [lightBot build guide](https://wiki.matttesch.com/lightbot) runs or installs: the ROS 2 packages,
scripts, systemd units, the robot's own programs and the local-AI tools. The paths match the guide, so a
chapter's `scripts/install_ch341.sh` is `scripts/install_ch341.sh` here.

Clone it where the guide expects the project (chapter 4):

```bash
mkdir -p ~/CCode && git clone https://github.com/burgerbarn/PublicRobot.git ~/CCode/rosorin-pro
```

This is a generated copy of the owner's private project repository (`guide/publish_scripts.sh` there). Not
included: the owner's home map (chapter 17 makes your own), voice recordings and the wake-word models
trained on his voice (chapter 26 trains your own), the project's records (`docs/`). Two private values are
placeholders: the package maintainer e-mail and the web-search host (`BUDDY_SEARCH_URL`, chapter 26).
No licence has been chosen yet, so the default copyright applies.
